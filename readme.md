# RL-IF

This repository contains code and experiments for RL-IF. It covers two settings: PPO training on standard RL benchmarks and RLHF fine-tuning for toxicity reduction. See [ppo_sb3/README.md](ppo_sb3/README.md) for the SB3 experiments and [rlhf/readme.md](rlhf/readme.md) for the RLHF experiments.
